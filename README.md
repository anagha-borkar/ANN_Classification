# ANN Classification

This project uses an Artificial Neural Network (ANN) to perform binary classification.

## Project Steps

1. Exploratory Data Analysis (EDA)
2. Data Preprocessing
3. Train-Test Split
4. Building the ANN Model
5. Model Compilation
6. Model Training
7. Model Evaluation
8. Confusion Matrix and Classification Report

## ANN Model

The ANN contains:

- Input: 4 features
- Hidden Layer 1: 64 neurons
- Hidden Layer 2: 32 neurons
- Output Layer: 1 neuron

## Model Settings

- Optimizer: Adam
- Learning Rate: 0.01
- Loss Function: Binary Crossentropy
- Metric: Accuracy
- Maximum Epochs: 100
- Validation Split: 20%
- Early Stopping: Used

## Results

Test Accuracy: **77.86%**

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
